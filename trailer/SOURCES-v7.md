# Sources for the revised connection cards

All footage, layouts, and source timings outside the CLI-agent and model cards are retained from v6. See [SOURCES-v6.md](SOURCES-v6.md) for the game recordings, setup-option references, fonts, and audio sources.

The two connection cards have no game footage. `connections-v7.py` renders original animated diagrams: a CLI agent connected through MCP to the table, and either an on-device local model or an API provider connected to the table. Moving connection pulses and rotating icosahedra provide animation. The terminal is an illustration, not a recorded configuration session or a runnable setup command.

The CLI tools remain grouped on one card. The model headline now says “Your model. Your choice.” to cover both local and API alternatives. Dice sounds belonging to the removed model-card ability-roll preview are removed; transition/connection sound accents use the retained Kenney samples. There is no music.
