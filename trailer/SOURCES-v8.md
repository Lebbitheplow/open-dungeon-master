# Sources for the new title and deployment cards

The opening title, server/client card, and closing title contain no game footage. `bookends-v8.py` renders original animated typography, rotating icosahedra, server hardware, desktop/phone silhouettes, moving geometry, and the website call to action. These are editorial illustrations, not recorded native application screens or deployment sessions.

The CLI-agent and model diagrams are retained from v7. All twelve gameplay shots remain byte-identical to their preceding encoded versions, with the same source timing and sound cues. See [SOURCES-v7.md](SOURCES-v7.md) and [SOURCES-v6.md](SOURCES-v6.md) for those recordings, feature references, fonts, and Kenney/game sound assets.

The server/client card illustrates self-hosting or opening the client app, whose embedded world can run without a separate server. The app supports Windows, macOS, Linux, and Android, as documented in the sibling client repository. Sound accents on the revised cards are editorial transitions; the removed map-generation click is replaced with a generic confirmation accent. There is no music.
