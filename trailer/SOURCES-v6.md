# Sources for the animated trailer with live footage windows

The game recordings are the same continuous dark-theme captures used by v4 and v5. [SOURCES-v2.md](SOURCES-v2.md) documents the isolated demo staging, real player/DM engine interactions, game dice samples, and Kenney CC0 foley. These recordings are decoded frame by frame and placed into large windows; no screenshots are used as video sources. Most gameplay action durations and their synchronized sounds retain the slower v4 timing.

The animated stage, headline entrances, framed windows, chapter rail, geometric accents, badges, and connecting paths are original code-drawn editorial graphics. They are not product interfaces. Opening game previews illustrate the setup choices; they are not recordings of native client setup or connected agent configuration sessions. The client app is documented as supporting Windows, macOS, Linux, and Android, and can host an embedded world or connect to a separate server.

The agent options share one opening card. Claude Code, Codex, opencode, and Grok Build are listed alongside other MCP clients. The visuals do not claim that a particular narrator adapter has passed a live validation on this machine. Feature references are the same local sources listed in [SOURCES-v5.md](SOURCES-v5.md), including the sibling client repository's README and `docs/agent-harness.md`.

The closing website address is the project's public `opendungeonmaster.com` domain, also referenced by the client documentation; it returned HTTP 200 during this edit. Fonts and foley are the retained game/CC0 assets. There is no music or generated score.
